# MIMEDICAPP Web

MIMEDICAPP es una aplicacion web academica orientada a adultos mayores y cuidadores para organizar tareas basicas de salud.

## Tech stack

- React
- Vite
- Tailwind CSS
- JavaScript
- React Router DOM
- Lucide React

## Instalacion

```bash
npm install
```

## Ejecucion

```bash
npm run dev
```

Luego abre la URL que muestre Vite, normalmente `http://localhost:5173`.

## Primera entrega

Esta version incluye solo frontend:

- Pantalla de login.
- Pantalla de registro.
- Navegacion entre login, registro y dashboard.
- Simulacion de inicio de sesion y creacion de cuenta.
- Dashboard principal responsive con modulos visuales.
- Cierre de sesion simulado.

No incluye backend, base de datos, APIs ni autenticacion real.
